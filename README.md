# Файлы для итогового задания

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.

1) Backend часть TaskTreker для работы с планировщиком задач

2) Задания со звездочкой выполнялись

3) В папке config названия переменных флагов , флаги можно передавать как через переменную окружения так же и через сами флаги
http://localhost:7540/

4) Запуск контейнера (порт по умолчанию 7540, база на хосте)


Пример команды:
docker run -d --name ws \
-p 7540:7540 \
-v /path/on/host/web:/app/web \
-v /path/on/host/db.sqlite:/data/todo.db \
-e TODO_PORT=7540 \
-e TODO_DBFILE=/data/todo.db \
mywebserver:latest

Что делает эта команда:

монтирует фронтенд (web) на хосте в /app/web внутри контейнера;

монтирует файл БД на хосте в /data/todo.db внутри контейнера;

устанавливает переменные окружения TODO_PORT и TODO_DBFILE;

пробрасывает порт 7540 из контейнера на 7540 на хосте.
